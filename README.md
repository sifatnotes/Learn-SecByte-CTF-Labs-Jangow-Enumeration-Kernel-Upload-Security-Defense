- **Jangow Labs:** Enumeration, firewall analysis, and root-oriented security scenarios.

- **Linux Privilege Escalation:** Understanding how enumeration can lead to higher-privilege access in controlled labs.

## Learning Path

A practical progression through these cybersecurity labs is:

1. Start with **basic enumeration and reconnaissance**.
2. Study **Jangow enumeration and firewall behavior**.
3. Explore exposed paths and overlooked application resources.
4. Learn how enumeration can contribute to **privilege-escalation chains**.
5. Study **kernel security** and Linux access boundaries.
6. Review **file-upload and injection defenses**.
7. Finish with detection-focused exercises to connect red-team activity with blue-team monitoring.

## How to Use the Labs

Use these exercises only in authorized lab environments.

Recommended workflow:

1. Read the lab objective before starting.
2. Identify the intended security concept.
3. Perform controlled reconnaissance against the provided target.
4. Document services, paths, configurations, and security weaknesses.
5. Investigate the challenge only inside the authorized environment.
6. Record the security impact and potential remediation.
7. For defensive exercises, identify controls that would prevent or detect the observed behavior.

For kernel, upload, injection, and privilege-escalation exercises, use isolated training environments and never test against systems without explicit authorization.
